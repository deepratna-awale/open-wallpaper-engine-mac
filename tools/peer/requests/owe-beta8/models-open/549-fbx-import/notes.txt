549: FBX import cases (WE 2.8.0.42), imported with the editor's Edit › Import Model in project p540_var

## (a) Sibling bone chains: siblings.fbx (make_siblings_fbx.py, Blender 5.2.2)
- **Source:** armature "Rig": root with two chains, **armL1 > armL2** and **armR1 > armR2**. Mesh "Bar" (4 x 0.3 x 0.3, subdivided) is skinned to the four chain bones by x position. One action "flap": the L1/R1 bones rotate ±45 deg about z over 30 frames.
- **Import dialog** (editor_import_dialog.png): material/texture settings only, as before.
- **siblings.mdl** (60698 B, MDLV0023). **MDLS bone order and parents:**
  - 0 RootNode (flags 0, parent -1)
  - 1 Rig (flags 0, parent 0)
  - 2 root (flags 1, parent 1)
  - 3 **armR1** (flags 1, parent 2)
  - 4 **armL1** (flags 1, parent 2)
  - 5 **armR2** (flags 1, parent 3)
  - 6 **armL2** (flags 1, parent 4)
  - So the importer orders bones **breadth-first** (both children of root, then their children), not one chain after the other. Within a level, R comes before L, so it isn't alphabetical; it is probably the FBX child order.
  - The flags match 509-D: 1 for armature bones, 0 for RootNode and the armature node.
- **Animation:** the FBX take imports as **"Scene"** (Blender exported the single action under the scene name, not "Rig|flap"). siblings.json `editor.animationmapping {"Scene": 52}`.
  - Added clip: `editor.clips [{"animation":"Scene","start":0,"end":30,"frameoffset":0,"id":26,"matchloop":true,"motionflags":43008,"name":"Scene (Clip 54)","rootmotion":""}]`.

## (b) Static mesh without skin: centered_cube.fbx (from 539)
- **centered_cube.mdl** (1344 B, MDLV0023): **no MDLS, no MDLA, no MDLE**. It is geometry and material only.
- **centered_cube.json:** `{"editor":{"animationmapping":null},"normals":true,"tangentspace":true}`. There is no `skinning` key; skinned models get `"skinning": true`.
- The 546 recompiles (bars.obj, flow.obj, pistols.fbx) are also static examples; see owe-beta7/models-open/546-fbx-import/recompiled/.

## (c) Add Event with a clip selected
- **Model Editor › Events tab:** the left list shows **Animations** (here "Scene"). **Add Event only creates something once an animation in that list is selected.** That's why 546's attempt did nothing: nothing was selected, and selecting a *clip* in the Animation tab is not enough.
- After selecting "Scene" › Add Event: an "Event (90)" entry appears, with **Event options: Name, Start frame**. Set name "flapmid", frame 15 (editor_event_dialog.png). OK › Save.
- **siblings.json:** `editor.events: [{"animation":"Scene","frame":15,"id":29,"name":"flapmid"}]`. The event is attached to the **source animation** ("Scene"), not to a clip id.
- **siblings.mdl** contains the string "flapmid" once (in or near MDLA0006), so the event is compiled into the model.
