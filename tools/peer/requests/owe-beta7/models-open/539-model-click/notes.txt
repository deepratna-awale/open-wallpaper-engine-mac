- **Scene** (make_539.py, scene.json): only that model, `camera eye 0 0 3 → centre 0 0 0`, and a SceneScript on the model's origin logging cursorEnter/Leave/Down/Click with `localPosition` / `worldPosition` / `hitBox`.
- **Run in the editor** (Run Preview + Log window). The cube's front face covered about x 746-1112, y 398-765 of the 1920×1080 editor screen, centre ≈ (929,582).
