## Character sheet
- **Layer right-click › Image Editing › Character Sheet Creation** opens the "Puppet Sheet Creation" dialog.
  - Limb list (starts with **Body**; **+** asks for a limb name).
  - Editing: polygon / brush tools, Mark Foreground / Mark Background / Erase, Brush size 20%, Reset Mask.
  - Fine-tuning: Fill gaps 15, Mask tolerance −1, Smoothing 1, Quality level 1.
  - View buttons: Original / limbs / …; Recalculate, **Auto Recalculate**, Help.
- **What I did:** + "Head" (brush-marked the head), + "Arm" (brush-marked the arm).
  - **The new limb nests under the selected limb**, so Arm became a child of Head: Body › Head › Arm (editor_limbs_view.png).
  - Then OK › "Confirm Puppet Sheet Creation: the existing layer will be removed … cannot be undone" › OK.
- **Result:** the layer was replaced by **figure3_sheet**:
  - scene object `size "352 372"`, **origin reset to 960 540** (the crop offset is gone)
  - models/figure3_sheet.json `{autosize, material}` with no cropoffset
  - figure3_sheet.tex-json: plain rgba8888, no crop keys
