## Source
- **skinned2.fbx** (make_skinned2_fbx.py, Blender 5.2.2):
  - Armature "Rig" (root › arm); a box skinned to root (lower half) / arm (upper half); a static, unskinned mesh "Plinth".
  - Two actions exported as takes: **wave** (arm rotates 0 › 60° › 0 over 30 frames) and **walk** (root moves +2 in X over 30 frames).

## Editor steps (project p540_var; editor_import_dialog.png)
- **Edit › Import Model.** The import dialog only offers material/texture settings.
- **Configure Model (Model Editor):**
  - **Animation:** "Animations" lists **Rig|walk** and **Rig|wave** (one per FBX take). Select Rig|walk › **Add Clip**; Clip options: Name, Start 0, End 30, Frame offset 0, Match loop on, **Motion root bone = root**.
  - **Attachments:** Add Attachment, name "hand_tip", Bone = **arm**.
  - **Events:** Add Event. **Event options stayed empty: nothing was created.** The event needs a different flow, probably a clip selected first, so it is not done.
  - **Constraints:** the bone list has arm / Plinth / Rig / root / RootNode. arm › Simulation preset **Gravity rotation**.
  - OK › Save.
